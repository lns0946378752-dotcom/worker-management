# Ứng dụng Next.js cũ (lưu tham khảo)

Đây là source Next.js được giữ lại từ repository ban đầu khi chuyển đồ án sang stack bắt buộc trong rubric.

Ứng dụng ở thư mục này **không còn là entrypoint của repo**. Phần chạy/nộp chính nằm ở `backend/`, `frontend/` và `database/`. Không chạy package hoặc cài dependency ở thư mục này trừ khi cần tham khảo source cũ.
