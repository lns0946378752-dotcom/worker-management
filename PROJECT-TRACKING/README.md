# Theo doi tien do va diem quan trong

Folder nay la so tay de tiep tuc du an tren may khac. No ghi lai quyet dinh, trang thai va cac diem can xem truoc khi sua code; khong thay the Git, tests, hay tai lieu rubric.

- [`system-impact.md`](./system-impact.md): cac thanh phan anh huong toan he thong va thay doi can kiem tra regression rong.
- [`feature-impact.md`](./feature-impact.md): luong va diem quan trong theo tung nhom chuc nang.
- [`SIX-STEP-CHECKLIST.md`](./SIX-STEP-CHECKLIST.md): tien do va khoang trong doi chieu voi tai lieu 6 buoc cua giang vien.
- [`ROADMAP.md`](./ROADMAP.md): phan tach MVP nop mon, dashboard tuyen dung va vision dashboard van hanh lao dong.
- [`PROMPT-AND-RESPONSE-LOG.md`](./PROMPT-AND-RESPONSE-LOG.md): prompt/phan hoi va quyet dinh duoc xac nhan trong cac phien tiep theo.
- [`SYSTEM-FUNCTION-MAP.md`](./SYSTEM-FUNCTION-MAP.md): bang tra cuu chuc nang, file code, request flow, quyen va database.
- Huong dan code cho nguoi moi: [`../SKILL/Codebase-Explanation.md`](../SKILL/Codebase-Explanation.md).
- Huong dan tao moi/reset project Supabase, tim SQL Editor va deploy Render/Vercel: [`../SKILL/Online-Demo-Deployment.md`](../SKILL/Online-Demo-Deployment.md).

Khi sua code, cap nhat file phu hop, ghi ro commit/branch, ngay gio, may, test va phan chua kiem chung. Khong ghi secret hoac du lieu that.
